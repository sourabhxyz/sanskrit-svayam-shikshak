# पाठ 4

## क्रिया

**प्रतिभाषेत्** = (वह) उत्तर दे (गा)। **पृच्छेयम्** = पूछूं (गा)। **प्रतिवदेत्** = (वह) उत्तर दे (गा)। **सेवसे** = (तू) सेवन करता है। **सेवते** = (वह) सेवन करता है। **सेवे** = (मैं) सेवन करता हूं। **संभाष्य** = बोलकर। **आपृच्छ्य** = पूछकर। **आदिशत्** = (उसने) आज्ञा की। **प्रक्षिपति** = (वह) फेंकता है। **निष्कास्यताम्** = निकाल दिया जाए। **परित्यज** = (तू) फेंक दे। **प्रतिवदेत्** = (वह) जवाब दे (गा)। **प्रत्यवदत्** = (उसने) उत्तर दिया। **प्रत्यब्रवीत्** = (उसने) उत्तर दिया। **अवदत्** = (वह) बोला।

## शब्द – पुल्लिंग

**भगवत्** = ईश्वर। **भगवतः** = ईश्वर का। **व्रजन्** = चलनेवाला। **पथिन्** = मार्ग। **पथि** = मार्ग में। **अर्भकः** = लड़का। **चरणः** = पांव। **देवः** = ईश्वर। **नृपः** = राजा। **प्रसादः** = दया। **पुरुषः** = मनुष्य। **इच्छन्** = इच्छा करता हुआ (अथवा करने वाला)। **ज्वरः** = बुख़ार। **आवेगः** = ज़ोर। **ज्वरावेगः** = बुख़ार का ज़ोर। **चिकित्सकः** = वैद्य। **वयस्यः** = मित्र। **यमः** = मृत्यु, यम। **क्षारः** = नमक। **चन्द्रः** = चांद। **अर्धचन्द्रम्** = गला पकड़कर (निकालना या धक्का देना)। **मन्दः** = मंद बुद्धिवाला। **परिजनः** = नौकर।

## स्त्रीलिंग

**गलहस्तिका** = गला पकड़ना (क्रिया)। **मृत्तिका** = मिट्टी।

## नपुंसकलिंग

**प्रतिवचनम्** = उत्तर, जवाब। **क्षतम्** = व्रण। **प्रतिवचः** = जवाब, उत्तर। **अरण्यम्** = वन।

## विशेषण

**विदग्ध** = ज्ञानी, विद्वान, पका हुआ। **बधिर** = बहिरा, न सुननेवाला। **अविदग्ध** = अज्ञानी। **आर्त** = रोगी, पीड़ित। **प्रस्थित** = प्रवास के लिए चला, मुसाफ़िर हो गया। **पृष्ट** = पूछा हुआ। **रुग्ण** = बीमार। **भद्र** = हितकारक। **सह्य** = सहने योग्य। **भद्रतर** = दोनों में अधिक अच्छा। **समर्थ** = शक्तिमान्। **भद्रतम** = सबसे अधिक अच्छा। **दुःसह** = सहन करने में कठिन। **प्रतिकूल** = विरोधी। **निःसारित** = निकाला हुआ। **अनुकूल** = मुआफ़िक़।

## अन्य (अव्यय)

**इति** = ऐसा। **सकोपम्** = गुस्से से। **बहिः** = बाहर। **सादरम्** = नम्रता के साथ। **सन्निकाशम्** = पास। **तदनु** = उसके पश्चात्। **तथैव** = वैसा ही। **तदनुरूपम्** = उसके अनुरूप (अनुकूल)।

उक्त शब्द कंठ करने के पश्चात् निम्न वाक्य स्मरण कीजिए –

## वाक्य

| संस्कृत | हिन्दी |
|---|---|
| (1) **कश्चित् पुरुषः स्वमित्रं द्रष्टुम् इच्छति।** | कोई पुरुष अपने मित्र को देखना चाहता है। |
| (2) **मित्रस्य सन्निकाशं गत्वा, स किं पृच्छति?** | वह मित्र के पास जाकर क्या पूछता है? |
| (3) **स मित्रसन्निकाशं गत्वा, अनुकूलं संभाष्य, पश्चात् तम् आपृच्छ्य, गृहम् आगमिष्यति।** | वह मित्र के पास जाकर, अनुकूल भाषण करके, बाद में उससे पूछकर, घर लौट आएगा। |
| (4) **स किं प्रतिवदति?** | वह क्या उत्तर देता है? |
| (5) **एवं स प्रतिकूलवचनं श्रुत्वा कुपितः।** | इस प्रकार विरुद्ध भाषण सुनकर वह गुस्सा हो गया। |
| (6) **स किं क्षते क्षारं प्रक्षिपति?** | वह क्यों घाव पर नमक डालता है? |
| (7) **तेन चौरः गलहस्तिकया गृहाद् बहिः निःसारितः।** | उसने चोर का गला पकड़कर घर से बाहर निकाल दिया। |
| (8) **स रुग्णः सकोपम् उच्चैः अवदत्।** | वह रोगी गुस्से में ऊंची आवाज़ में बोला। |

## (2) अविदग्धस्य बधिरस्य कथा – अज्ञानी बहिरे की कथा

| संस्कृत | हिन्दी |
|---|---|
| (1) **कोऽपि बधिरः स्वमित्रं ज्वरार्त्तं श्रुत्वा, तं द्रष्टुमिच्छन्, गृहात् प्रस्थितः। पथि व्रजन् एवम् अचिंतयत्।** | (1) कोई बहिरा अपना मित्र ज्वर से पीड़ित है (ऐसा) सुनकर, उसको देखने की इच्छा करता हुआ घर से चला। मार्ग में जाता हुआ ऐसा सोचने लगा। |
| (2) **मित्रसन्निकाशं गत्वा 'अपि सह्यो ज्वरावेगः' इति पृच्छेयम्। 'किंचिद् इव सह्यः' इति स प्रतिवदेत्।** | (2) मित्र के पास जाकर 'क्या बुख़ार सहन करने योग्य (है),' यह पूछूंगा। 'थोड़ा ही सहन करने योग्य है!' ऐसा वह उत्तर देगा। |
| (3) **ततः 'किम् औषधं सेवसे' इति पृच्छेयम्। 'इदम् औषधं सेवे' इति प्रतिभाषेत। अनन्तरं 'कस्ते चिकित्सकः'? इति मया पृष्टः 'असौ मम चिकित्सकः' इति प्रतिवदेत्।** | (3) फिर 'क्या दवा लेते हो?' ऐसा पूछूंगा। 'यह दवा लेता हूं' ऐसा वह उत्तर देगा। पश्चात् 'कौन तुम्हारा वैद्य (है)' ऐसा मेरे पूछने पर 'अमुक मेरा वैद्य है' ऐसा वह उत्तर देगा। |
| (4) **अथ तत्तदनुरूपं संभाष्य, मित्रम् आपृच्छ्य, गृहम् आगमिष्यामि।** | (4) अनन्तर इस प्रकार अनुकूल बोलकर, मित्र से पूछ-ताछकर घर आ जाऊंगा। |
| (5) **एवं चिन्तयन् मित्रं प्राप्य, सादरम् अपृच्छत् "वयस्य, अपि सह्यो ज्वरावेगः?" इति। "तथैव वर्तते। न विशेषः" इति स प्रत्यवदत्।** | (5) इस प्रकार विचार करता हुआ मित्र (के पास) पहुंचकर, आदर के साथ पूछा – "मित्र क्या सहन करने योग्य बुख़ार का ज़ोर (है)"। "वैसा ही है, कोई फ़र्क़ नहीं", ऐसा वह जवाब में बोला। |
| (6) **"भगवतः प्रसादेन तथैव वर्तताम्। कीदृशम् औषधं सेवसे?" इति। ज्वरार्तः प्रत्यब्रवीत् "मम औषधं मृत्तिका एव" इति।** | (6) "परमेश्वर की कृपा से वैसा ही रहे। कौन-सी औषध लेते हो?" ऐसा पूछने पर रोगी ने "मेरी दवा मिट्टी ही है" ऐसा प्रत्युत्तर दिया। |
| (7) **वयस्यः प्राह – "तदेव भद्रतरम्।" "कस्ते चिकित्सकः" इति।** | (7) मित्र बोला – "वही अधिक हितकारी (है)।" "कौन-सा तेरा वैद्य (है)?" |
| (8) **रुग्णः सकोपम् अब्रवीत् "मम भिषग् यम एव" इति।** | (8) रोगी क्रोध से बोला – "मेरा वैद्य यम ही (है)।" |
| (9) **बधिरः प्रोवाच – "स एव समर्थः तं मा परित्यज" इति।** | (9) बधिर बोला – "वही शक्तिमान है, उसको न छोड़।" |
| (10) **एवं प्रतिकूलं प्रतिवचनं श्रुत्वा स रोगी दुःसहेन कोपेन समाविष्टः परिजनम् आदिशत्।** | (10) इस प्रकार विरोधी वचन सुनकर उस रोगी ने असह्य क्रोध से युक्त होकर नौकर को आज्ञा की। |
| (11) **"भोः कथम् अयम् एवं क्षते क्षारं प्रक्षिपति। निष्कास्यताम् अयम् अर्धचन्द्रदानेन" इति।** | (11) "अरे क्यों यह इस प्रकार ज़ख़्म पर नमक डालता है। निकाल दे, इसको गला पकड़कर।" |
| (12) **अथ स बधिरो मंदधीः परिजनेन गलहस्तिकया बहिः निःसारितः।** | (12) पश्चात् उस मूर्ख बधिर को नौकर ने गला पकड़कर बाहर निकाला। |
| (कथा-कुसुमाञ्जलेः) | (कथा कुसुमाञ्जलि) |

नोट – हिन्दी में 'इति' शब्द का सब जगह भाषान्तर नहीं होता। संस्कृत के मुहावरे भी भाषा के मुहावरों से भिन्न होते हैं। यहां संस्कृत की शब्द-रचना के अनुसार ही हिन्दी की वाक्य-रचना रखी है। इस कारण भाषान्तर अटपटा लगेगा, और उसे सही ढंग से समझ लेना चाहिए।

## समास-विवरण

1. **स्वमित्रम्** – स्वस्य मित्रं = स्वमित्रम्, स्ववयस्यः।
2. **ज्वरार्तः** – ज्वरेण आर्तः = पीड़ितः, ज्वरपीड़ितः।
3. **ज्वरावेगः** – ज्वरस्य आवेगः = ज्वरावेगः।
4. **सादरम्** – आदरेण सहितम् = आदरयुक्तम्।
5. **सकोपम्** – कोपेन सहितं = सकोपम्, सक्रोधम् इत्यर्थः।
