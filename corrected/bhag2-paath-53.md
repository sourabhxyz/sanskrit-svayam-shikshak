### अधि + इ (अधी) (अध्ययने) = अध्ययन करना

**वर्तमान काल**

| | | |
|---|---|---|
| **अधीते** | **अधीयाते** | **अधीयते** |

| **अधीये** | **अधीवहे** | **अधीमहे** |

**भविष्यकाल**

| | | |
|---|---|---|
| **अध्येष्यते** | **अध्येष्येते** | **अध्येष्यन्ते** |
| **अध्येष्यसे** | **अध्येष्येथे** | **अध्येष्यध्वे** |
| **अध्येष्ये** | **अध्येष्यावहे** | **अध्येष्यामहे** |

| | | |

यही धातु परस्मैपद में भी है जिसका अर्थ 'अधि + इ (स्मरणे) = स्मरण करना' है। इसके रूप –

**परस्मैपद। वर्तमान काल**

| | | |
|---|---|---|
| **अध्येति** | **अधीतः** | **अधीयन्ति** |
| **अध्येषि** | **अधीथः** | **अधीथ** |
| **अध्येमि** | **अधीवः** | **अधीमः** |

**परस्मैपद। भविष्यकाल**

| | | |
|---|---|---|
| **अध्येष्यति** | **अध्येष्यतः** | **अध्येष्यन्ति** |
| **अध्येष्यसि** | **अध्येष्यथः** | **अध्येष्यथ** |
| **अध्येष्यामि** | **अध्येष्यावः** | **अध्येष्यामः** |

**परस्मैपद। भूतकाल**

| | | |
|---|---|---|
| **अध्यैत्** | **अध्यैताम्** | **अध्यायन्** |
| **अध्यैः** | **अध्यैतम्** | **अध्यैत** |
| **अध्यायम्** | **अध्यैव** | **अध्यैम** |

इनके उभयपद के ये सब रूप विशेष उपयोगी होने से ठीक स्मरण रखने चाहिएँ।

### द्विष् (अप्रीतौ) = द्वेष करना – उभयपद

| **द्वेक्षि** | **द्विष्ठः** | **द्विष्ठ** |
| **द्वेष्मि** | **द्विष्वः** | **द्विष्मः** |

'द्विष्' धातु का भविष्यकाल 'द्वेक्ष्यति, द्वेक्ष्यते' ऐसा होता है। उसके रूप सुगम हैं।

## वाक्य

| | |
|---|---|
| 1. **अहं तम् अद्विषि।** | मैं उसको द्वेष करता था। |
| 2. **ते सर्वेऽपि तम् अद्विषन्।** | वे सब भी उसको द्वेष करते थे। |
| 3. **त्वं किमर्थं द्वेक्षि?** | तू क्यों द्वेष करता है? |
| 4. **युवां न द्विष्ठः।** | तुम दोनों द्वेष नहीं करते। |
| 5. **आवां ह्यः अजागृव।** | हम दोनों कल जागते रहे। |
| 6. **त्वं श्वः जागरिष्यसि किम्?** | क्या तू कल जागेगा? |
| 7. **सर्वे वयम् अद्य जागृमः।** | हम सब आज जागते हैं। |
| 8. **ईश्वरो द्विपदश्चतुष्पदः ईष्टे।** | परमेश्वर द्विपाद और चतुष्पादों पर प्रभुत्व करता है। |
| 9. **अहं व्याकरणं नाध्यैयि।** | मैंने व्याकरण पढ़ा नहीं। |
| 10. **किमधीषे?** | तू क्या पढ़ता है? |
| 11. **स ज्यौतिषमध्येष्यते।** | वह ज्योतिष पढ़ेगा। |
| 12. **तौ गणितम् अधीयाते।** | वे दोनों गणित पढ़ते हैं। |
| 13. **आस्ते स तत्र।** | बैठा है वह वहाँ। |
| 14. **वयं सर्वे अत्रैवास्महे।** | हम सब यहाँ ही बैठते हैं। |
| 15. **युवां तत्र आसिष्येथे।** | तुम दोनों वहाँ बैठोगे। |
| 16. **अहं नैव तत्रासिष्ये।** | मैं वहाँ नहीं बैठूँगा। |
| 17. **कस्तत्रासिष्यते?** | कौन वहाँ बैठेगा? |
