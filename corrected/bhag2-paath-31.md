# पाठ 31

अब हम बताएंगे कि स्त्रीलिंग सर्वनामों के रूप किस प्रकार बनते हैं।

## आकारान्त स्त्रीलिंग 'सर्वा' शब्द

| | एकवचन | द्विवचन | बहुवचन |
|---|---|---|---|
| 1. | **सर्वा** | **सर्वे** | **सर्वाः** |
| सम्बोधन | **(हे) सर्वे** | " | " |
| 2. | **सर्वाम्** | **सर्वे** | **सर्वाः** |
| 3. | **सर्वया** | **सर्वाभ्याम्** | **सर्वाभिः** |
| 4. | **सर्वस्यै** | " | **सर्वाभ्यः** |
| 5. | **सर्वस्याः** | " | " |
| 6. | " | **सर्वयोः** | **सर्वासाम्** |
| 7. | **सर्वस्याम्** | " | **सर्वासु** |

इसी प्रकार 'पूर्वा, परा, दक्षिणा, उत्तरा, अपरा, अधरा, नेमा' इत्यादि सर्वनामों के रूप बनते हैं।

'प्रथमा, चरमा, द्वितया, त्रितया, अल्पा, अर्धा, कतिपया' इत्यादि सर्वनाम स्त्रीलिंग होते हुए भी 'विद्या' के समान चलते हैं। इनके पुल्लिंग रूप 'देव' के समान चलते हैं।

'द्वितीया, तृतीया' शब्दों के चतुर्थी से सप्तमी तक के एकवचन के रूप दो-दो प्रकार के होते हैं। जैसे –

## आकारान्त स्त्रीलिंग 'द्वितीया' शब्द

| | एकवचन | द्विवचन | बहुवचन |
|---|---|---|---|
| 1. | **द्वितीया** | **द्वितीये** | **द्वितीयाः** |
| सम्बोधन | **(हे) द्वितीये** | " | " |
| 2. | **द्वितीयाम्** | " | " |
| 3. | **द्वितीयया** | **द्वितीयाभ्याम्** | **द्वितीयाभिः** |
| 4. | **द्वितीयस्यै, द्वितीयायै** | " | **द्वितीयाभ्यः** |
| 5. | **द्वितीयस्याः, द्वितीयायाः** | " | " |
| 6. | " " | **द्वितीययोः** | **द्वितीयानाम्, द्वितीयासाम्** |
| 7. | **द्वितीयस्याम्, द्वितीयायाम्** | **द्वितीययोः** | **द्वितीयासु** |

इसी प्रकार तृतीया शब्द चलता है।

## 'यत्' शब्द स्त्रीलिंग

| | एकवचन | द्विवचन | बहुवचन |
|---|---|---|---|
| 1. | **या** | **ये** | **याः** |
| 2. | **याम्** | " | " |
| 3. | **यया** | **याभ्याम्** | **याभिः** |
| 4. | **यस्यै** | " | **याभ्यः** |
| 5. | **यस्याः** | " | " |
| 6. | " | **ययोः** | **यासाम्** |
| 7. | **यस्याम्** | " | **यासु** |

इसी प्रकार 'अन्या, अन्यतरा, इतरा, कतरा, कतमा, त्वा' इत्यादि सर्वनामों के रूप बनते हैं।

'अन्यतमा' शब्द सर्वनाम होते हुए भी, विद्या के समान उसके रूप बनते हैं, यह बात ध्यान रखनी चाहिए।
